九州研修旅行

令和8年（2026年）10月20日（火）〜10月23日（金）〈3泊4日〉

創立者・廣池千九郎先生の生家を訪ね、日本の歴史と文化の源流をたどり、
異なる風土に触れ、先生方や友人との絆を深める研修です。

Day 110/20 火 Day 210/21 水 Day 310/22 木 Day 410/23 金

行程の概要

  • 10/20（火）
    羽田 → 大分空港 → 宇佐神宮 → 青の洞門 → 中津記念館 → 別府温泉
    宿泊：別府 城島高原ホテル
  • 10/21（水）
    別府 → 高千穂（神社・峡・天岩戸） → 阿蘇
    宿泊：阿蘇 ホテル角萬　※2グループで見学順が異なります
  • 10/22（木）
    阿蘇 → 知覧 → 長崎鼻 → 指宿温泉
    宿泊：指宿海上ホテル
  • 10/23（金）
    指宿 → 鹿児島（自由行動） → 鹿児島空港 → 羽田
    荷物発送 07:30　再集合 14:20

研修の主旨

  1. 創立者・廣池千九郎先生の生家を訪ね、モラロジー理解の一助とする
  2. 日本の歴史と文化の源流をたどり、先人の努力や犠牲を学ぶ
  3. 異なる風土・自然に触れ、教科書では得られない知識を深める
  4. 先生方や友人と寝食を共にし、規律と絆を深める
