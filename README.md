## デザイン・機能

- **放射状メニュー**（長押し / トリプルタップ）＋ **ハンバーガーFAB**（reitansai方式）
- **天気・時間帯連動** atmosphere（Open-Meteo、座標は現在地に応じて更新）
- **現在地連動**：位置情報許可で最寄り訪問地バッジ＋日程ナビのハイライト

- 各ページ専用CSS/JS + `default.css` / `default.js`
